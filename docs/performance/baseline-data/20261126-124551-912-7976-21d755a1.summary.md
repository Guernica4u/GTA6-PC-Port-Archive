## Definitions

- stall window = CSV window whose slowest frame >= max(200 ms, 3 x the median ms/frame of its span) (threshold shown per span); stalled time is a lower bound (one max per window).
- watchdog stall = a `stall:` log line group (same frame number); length = largest stalled_ms; cause = `inside:` text.
