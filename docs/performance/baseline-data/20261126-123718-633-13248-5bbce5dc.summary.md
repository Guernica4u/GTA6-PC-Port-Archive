## Definitions

- stall window = CSV window whose slowest frame >= max(200 ms, 3 x the median ms/frame of its span) (threshold shown per span); stalled time is a lower bound (one max per window).
- watchdog stall = a `stall:` log line group (same frame number); length = largest stalled_ms; cause = `inside:` text.

- ms_*_reconstructed: per window one frame at the logged max and the rest at the remaining mean; exact in frame count, total time and window max, a model in between. 1% low = 1000/P99 (fps_1pct_low_p99) and mean fps of the slowest 1% frames.

- per_frame_subsystems_heavy = plain mean over log lines at/after world entry; each line is one window's per-frame figure; subsystem ms are summed over threads (they can exceed the frame time).
